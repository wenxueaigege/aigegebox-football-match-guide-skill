# 海报排版规范

## 完整长图

1. 顶部：赛季、队徽或文字标识、球队名称、中国大陆看球赛程、生成时间。
2. 近期看球：按查询基准日期展示接下来最多 5 场尚未结束的比赛和转播状态。
3. 按赛事分区：联赛、国内杯赛、欧战、超级杯、世俱杯、友谊赛等。
4. 每个赛事内按月份排列。
5. 比赛较少的月份单栏；比赛较密集的月份双栏。
6. 季前赛和已确认的社区盾单独展示；其他超级杯、国内杯赛和欧冠按球队配置进入下方杯赛区，避免重复。
7. 杯赛表格采用浅色三组表头和双行卡式结构：表头显示“日期 / 时间、对手 / 转播渠道、主客 / 比赛场地”，正文上行显示日期/轮次、对手和主客，下行显示时间、转播渠道和比赛场地；未知场地显示“场地待定”。
8. 杯赛和直播渠道汇总采用双列紧凑布局，减少长图高度。
9. 底部：转播说明、数据来源、待确认项目和更新时间。

## 已结束比赛

- 渲染海报时以 `asOfDate`、`lastCheckedAt` 或当前生成日期为基准。
- 基准日前的比赛、明确标记为已结束的比赛和已取消比赛不进入当前海报。
- 原始赛程 JSON、校验结果和覆盖报告仍保留历史比赛，便于后续生成历史版本。

## 联赛卡片

- 所有比赛卡片日期色卡统一使用球队主色；联赛主场标签使用深色主色、客场标签使用球队辅助色，并同时显示文字标签。阿森纳继续使用红色日期区和黄色客场标签，皇马等球队按各自视觉配置生成。
- 比赛日期显示为“8月22日 周六”，下方显示北京时间；日期待定时不生成星期。
- 白色区域左下显示直播渠道，右上显示主客场，右下显示比赛球场；辅助文字优先保证手机端可读。
- 顶部标题优先横向排列，减少纵向占用；队徽优先使用官方 SVG，并通过 `preserveAspectRatio="xMidYMid meet"` 保持原始比例，禁止拉伸。

## 输出取舍

- 当前只生成完整赛季长图，不再默认生成独立分享卡片。
- 长图本身保留二维码和主页链接，便于保存、转发和引流。
- 过去试运行目录中的分享卡片文件作为历史产物保留，但不再进入新的渲染清单。
- 完整长图底部主页文字保持醒目但不压过球队名称和赛事信息。
- 杯赛字段表头使用米白/浅灰背景、深色文字和细金色底线，不使用大面积亮红色。
- 杯赛模块由赛事注册表驱动；`expectedCompetitions` 只属于覆盖报告，不用于决定海报分区。长赛事可按行拆分双列，短赛事按赛事面板成对排列。

使用 SVG/HTML 生成，确保中文、日期和表格内容不由图片模型生成。SVG 是长期保留的矢量母版；默认另用 `rsvg-convert` 输出 4 倍 PNG，便于手机查看和社交平台发布。本机缺少工具时，macOS 运行 `brew install librsvg`。
